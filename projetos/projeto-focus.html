Visão Geral

O Projeto Focus é um pipeline enxuto que automatiza uma tarefa simples e recorrente: acompanhar o Boletim Focus do Banco Central do Brasil. Toda segunda-feira de manhã ele coleta as expectativas de mercado para as quatro variáveis macro mais acompanhadas — IPCA, Câmbio, Selic e PIB — calcula a variação semanal das medianas e gera um relatório legível em Markdown.

O diferencial está na entrega: em vez de cron/launchd na máquina local, quem dispara o ciclo é um routine agendado do Claude Code (/schedule) — um agente remoto que roda o pipeline e envia o resumo por e-mail automaticamente. O resultado chega na caixa de entrada sem nenhuma intervenção manual.

NoteComo se diferencia do Previsão Macro

Este não é um projeto de forecasting. Enquanto o Previsão Macro gera previsões próprias (ensemble de modelos clássicos + foundation models, dashboard Shiny, validação estatística contra o Focus), o Projeto Focus apenas lê e resume as expectativas do próprio Focus. É um digest informativo, leve e sem modelagem — pensado para chegar pronto no e-mail toda segunda.

Motivação

O Boletim Focus é divulgado pelo BCB às segundas-feiras de manhã, consolidando as expectativas coletadas até a sexta anterior. Abrir o site, baixar os dados e comparar com a semana passada é um ritual manual que se repete toda semana. O projeto elimina esse atrito com três escolhas deliberadas:

  1. Sem chaves nem segredos — a API de Expectativas de Mercado do BCB é pública e não exige autenticação;
  2. Saída em Markdown — versionável, legível e fácil de embutir no corpo de um e-mail;
  3. Entrega zero-touch — o routine do Claude Code roda o pipeline e despacha o resumo sozinho.

Fonte de dados

API de Expectativas de Mercado do BCB (Olinda / OData, pública e sem autenticação).

  • Base: https://olinda.bcb.gov.br/olinda/servico/Expectativas/versao/v1/odata
  • Endpoint: ExpectativasMercadoAnuais — expectativas por ano-referência
  • Filtro padrão: baseCalculo eq 0 (amostra completa de respondentes)
  • Campos: Indicador, Data, DataReferencia, Media, Mediana, DesvioPadrao, Minimo, Maximo, numeroRespondentes
ID Indicador (API) Descrição Unidade
ipca IPCA Inflação (IPCA) esperada % a.a.
cambio Câmbio Taxa de câmbio R\(/US\) R\(/US\)
selic Selic Taxa básica de juros (meta) % a.a.
pib PIB Total Crescimento do PIB % a.a.

Os nomes em “Indicador (API)” precisam bater exatamente com os valores retornados pela API (atenção à acentuação, ex.: Câmbio).

Fluxo do pipeline

flowchart LR
  BCB[(API Expectativas<br>BCB / Olinda)] --> COL[collector.py<br>coleta + retry/backoff]
  COL --> RAW[(data/raw/<br>CSV por indicador)]
  RAW --> TRA[transform.py<br>foto recente + variação semanal]
  TRA --> PROC[(data/processed/<br>CSV consolidado)]
  PROC --> REP[report.py<br>relatório Markdown]
  REP --> OUT[(reports/latest.md<br>+ focus_AAAA-MM-DD.md)]
  ROUT[Routine Claude Code<br>agendado] -.dispara.-> COL
  OUT -.resumo.-> MAIL([E-mail semanal])

  1. Coleta (collector.coletar_todos) — consulta a API para cada indicador numa janela de 30 dias (traz divulgações suficientes para a variação), com retry/backoff porque a API do BCB ocasionalmente oscila;
  2. Persistência bruta — CSV por indicador em data/raw/;
  3. Transformação (transform.consolidar) — extrai a foto mais recente por ano-referência e calcula a variação frente à divulgação anterior;
  4. Persistência consolidada — CSV achatado em data/processed/;
  5. Relatório (report.gerar_markdown) — gera reports/focus_<data>.md e atualiza reports/latest.md.

Exemplo de saída

Trecho do relatório gerado (divulgação de 29/05/2026):

Variável Ano-ref. Mediana Var. semanal Respondentes
IPCA (% a.a.) 2026 5,09% ▪️ 0,00 154
Câmbio (R\(/US\)) 2026 R$ 5,16 ▪️ 0,00 122
Selic (% a.a.) 2026 13,25% ▪️ 0,00 157
PIB Total (% a.a.) 2026 1,90% 🔺 +0,01 116

A variação semanal compara a mediana da divulgação mais recente com a imediatamente anterior. 🔺 = revisada para cima, 🔻 = para baixo, ▪️ = estável. O relatório completo cobre os anos-referência 2026 a 2029 para cada variável.

Automação — routine do Claude Code

O repositório inclui scripts/run_weekly.sh (ativa o .venv, roda o pipeline e registra log datado), compatível com cron ou launchd. Mas a forma adotada é o routine do Claude Code:

  • um agente agendado via /schedule roda toda segunda de manhã;
  • executa o pipeline, lê o reports/latest.md gerado;
  • envia o resumo por e-mail — fechando o ciclo coleta → relatório → entrega sem máquina ligada nem servidor próprio.
# Agendamento clássico equivalente (cron, toda segunda às 09:00)
0 9 * * 1 /caminho/Projeto_Focus/scripts/run_weekly.sh
